## Smart Health & Wellness Management System

Preventive Daily Habit Tracking & Wellness Companion — Aligned with UN SDG 3

## Overview

Smart Health & Wellness Management System is a zero-dependency, responsive web application built to help students and busy individuals turn preventive health awareness into consistent daily habits. It tracks hydration, sleep, exercise, mental stress, BMI, and sports nutrition in one unified dashboard.

## Key Features

User Accounts & Demo Mode: Full Sign Up, Sign In, and Sign Out with per-user isolated localStorage data, plus a one-click Demo Student Account (Aarav Sharma).

Light & Dark Theme: Instant theme toggle between warm daylight mode and deep emerald dark mode.

Live Dashboard & Mood Check-In: Real-time Daily Wellness Score (%), quick +1 Glass Water / +15m Walk actions, and a 5-state Mood & Academic Stress tracker.

Daily Habit Loggers: Interactive 250ml water glass grid, sleep duration slider with quality ratings, and workout session logger.

BMI, Protein & Creatine Hydration Calculator: Computes BMI category, activity-based daily protein ranges (g/day), and extra hydration adjustments (+600ml maintenance / +1000ml loading) for Creatine Monohydrate with one-click goal syncing.

Smart Reminders & Weekly Analytics: Customizable toast notifications, a 7-day progress chart, .csv report export, and filterable preventive wellness guides.

## Tech Stack & Quick Start

Frontend: HTML5, CSS3 (Custom Properties), Tailwind CSS, Vanilla JavaScript

Run Locally: Simply open index.html in any modern web browser—no server or build tools required.
